The only icon component. Lucide, 1.75px stroke, 24px grid, always `currentColor`. Never inline a hand-written SVG.

```jsx
<Icon name="calendar-check" size={20} />
<Icon name="scissors" size={16} strokeWidth={2} />
```

51 icons are available (see assets/icons/). Add more by copying the SVG from lucide-icons/lucide into assets/icons/ and adding its inner markup to the map in Icon.jsx.
